# Hermes Agent Design

Hermes Agent 架构设计文档站。

## 项目结构

```
hermes-agent-design/
├── README.md           # 本文件
├── SPEC.md             # 系统规格说明
├── architecture.md     # 架构设计文档
├── docs/               # 详细设计文档
│   ├── index.md
│   ├── core/           # 核心模块设计
│   ├── agent/          # Agent 设计
│   ├── tools/          # 工具系统设计
│   └── platform/       # 平台集成设计
├── website/            # Docusaurus 文档站
└── dashboard/          # WebUI 管理面板
```

## 快速开始

### 本地预览文档站

```bash
cd website
npm install
npm run dev
```

访问 `http://localhost:3000`

### 查看架构文档

直接浏览 `docs/` 目录或访问在线站点。
