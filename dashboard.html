Hermes Agent Dashboard

React + TypeScript + Vite WebUI for managing the Hermes Agent framework. Provides model selection, session management, plugin configuration, and real-time monitoring.

Technology Stack

FrameworkVue 3 + Vuetify 3
LanguageTypeScript
BundlerVite
StatePinia
RouterVue Router
HTTPAxios
APIWebSocket + REST

Dashboard Pages

Model Picker

Select and configure LLM providers. Switch between OpenAI, Anthropic, Gemini, MiniMax, GLM, Ollama, and custom endpoints.

ProviderPage.vue ModelPicker.vue modelStore

Session Management

View, search, and manage conversation sessions. Full-text search with SQLite FTS5, session history, and trajectory compression.

SessionManagementPage.vue sessionStore ConversationPage.vue

Configuration UI

Comprehensive settings panel with theme customization, proxy configuration, API key management, and system controls.

Settings.vue ConfigForm.vue configStore

Extension System

Browse and manage plugins. View installed extensions, browse the plugin market, and configure extension preferences.

ExtensionPage.vue InstalledPluginsTab.vue MarketPluginsTab.vue

Platform Integration

Configure multi-platform messaging gateways: Telegram, Discord, Feishu, QQ, and custom webhooks.

PlatformPage.vue gateway/adapters/

Persona Management

Create and organize AI personas with folder-based organization. Drag-and-drop interface with persona cards.

PersonaPage.vue PersonaManager.vue FolderTree.vue

website/src/ Components

The dashboard UI is built with reusable Vue components located in dashboard/src/:

layouts/

Page layout wrappers providing consistent structure across the dashboard.

FullLayout.vue VerticalSidebar.vue VerticalHeader.vue FloatingLayout.vue BlankLayout.vue

views/

Page-level components representing each dashboard route and feature.

Settings.vue ProviderPage.vue PlatformPage.vue SessionManagementPage.vue ExtensionPage.vue PersonaPage.vue StatsPage.vue TracePage.vue

components/ (shared)

Reusable UI components shared across multiple views and pages.

ModelPicker.vue ProxySelector.vue SidebarCustomizer.vue StorageCleanupPanel.vue

stores/ (Pinia)

State management stores for reactive data across the application.

sessionStore configStore modelStore pluginStore

Running the Dashboard

# Install dependencies cd dashboard pnpm install # Start development server pnpm dev # Production build pnpm build # Preview production build pnpm preview

The dashboard runs on http://localhost:3000 by default and connects to the Hermes Agent API server at http://localhost:6185.
