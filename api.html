HTTP API Documentation

Hermes Agent ACP Protocol HTTP API — Programmatic access to agent capabilities via RESTful endpoints. Authenticate with API keys and integrate into any workflow.

Authentication

All API requests require authentication via API key. Include your key in the request headers:

Authorization: Bearer your_api_key_here

Alternative header format:

X-API-Key: abk_xxxxxxxxxxxx

API Key Create your API key in WebUI → Settings

Core Endpoints

POST /api/v1/chat
Send a chat message. Returns SSE stream. Server generates UUID when session_id is omitted.
GET /api/v1/chat/sessions
List sessions for a specific username with pagination.
POST /api/v1/chat/new_session
Create a new chat session for a user.
POST /api/v1/chat/batch_delete_sessions
Delete multiple chat sessions in batch.
GET /api/v1/configs
List available configuration files.
POST /api/v1/file
Upload attachment for chat context.

Instant Messaging (UMO)

POST /api/v1/im/message
Send proactive message via Unified Message Interface.
GET /api/v1/im/bots
List connected bot/platform IDs.

Plugin & Extension API

GET /api/v1/plugin/get
Get installed plugin list.
GET /api/v1/plugin/detail
Get detailed plugin information by name.
GET /api/v1/plugin/market_list
List available plugins from marketplace.
POST /api/v1/plugin/install
Install a new plugin.
POST /api/v1/plugin/uninstall
Uninstall a plugin.
POST /api/v1/plugin/update
Update a plugin to latest version.

Tool Calling

Tool calling enables the agent to interact with external systems. Tools are auto-discovered via the registry pattern and can be invoked during conversation.

terminal

Execute shell commands on the host system. Useful for system administration tasks.

file

Read, write, and manage files. Supports path operations with security validation.

web

Web search and content fetching. Power search and research capabilities.

code

Python code interpreter for dynamic computation and data analysis.

Tool Schema Format

{ "name": "web_search", "description": "Search the web for information", "parameters": { "query": { "type": "string", "description": "Search query" } } }

Session Management

Sessions track conversation history with automatic compression and intelligent truncation. Each user maintains independent session context.

Request Parameters

Parameter Type Required Description
username string * User identifier for session scoping
session_id string (UUID) Specific session to continue. Auto-generated if omitted.
message string * The message content to send
stream boolean Enable SSE streaming response (default: true)

Create New Session

# Create a new chat session curl -X POST 'http://localhost:6185/api/v1/chat/new_session' \ -H 'Authorization: Bearer your_api_key' \ -H 'Content-Type: application/json' \ -d '{"username": "alice", "session_id": "optional-existing-id"}'

Code Examples

Send Chat Message (Python)

import requests import json # Send a chat message with streaming response url = "http://localhost:6185/api/v1/chat" headers = { "Authorization": "Bearer your_api_key", "Content-Type": "application/json" } payload = { "message": "Hello, list my files in /tmp", "username": "alice" } response = requests.post(url, headers=headers, json=payload, stream=True) for line in response.iter_lines(): if line: print(line.decode('utf-8'))

cURL Example

# List user sessions curl -X GET 'http://localhost:6185/api/v1/chat/sessions?username=alice' \ -H 'Authorization: Bearer your_api_key' # Send chat message curl -N 'http://localhost:6185/api/v1/chat' \ -H 'Authorization: Bearer your_api_key' \ -H 'Content-Type: application/json' \ -d '{"message":"Hello","username":"alice"}'

Proactive Message (JavaScript)

// Send proactive message to user via UMO const response = await fetch('http://localhost:6185/api/v1/im/message', { method: 'POST', headers: { 'Authorization': 'Bearer your_api_key', 'Content-Type': 'application/json' }, body: JSON.stringify({ platform: 'telegram', user_id: '123456789', message: 'Hello from Hermes Agent!' }) });

ACP Protocol

The Agent Communication Protocol (ACP) is Hermes Agent's message format for structured communication between clients and the agent runtime.

ACP Message Structure

{ "acp_version": "1.0", "type": "chat.request" | "chat.response" | "tool.call" | "tool.result", "payload": { "session_id": "uuid", "message": "user input", "context": {} }, "metadata": { "timestamp": "ISO8601", "user_id": "string" } }

Message Types

chat.request

User message with optional session context for continuing conversations.

chat.response

Agent response with text content and optional tool calls.

tool.call

Request to execute a registered tool with parameters.

tool.result

Result of tool execution returned to agent for synthesis.
